# Amazon Clone

The **Amazon Clone** is a responsive front-end website created using **HTML and CSS**. It recreates an Amazon-inspired shopping homepage with a navigation bar, promotional banner, product-category cards, and footer.

This project focuses on website layout, styling, and responsive design. It is **not a complete e-commerce platform**: account login, cart management, checkout, and payments are not implemented.

## Technologies Used

- **HTML5** – Structures the webpage and its sections.
- **CSS3** – Styles the layout, colors, images, typography, and responsive design.

No JavaScript is used in this project.

## Website Sections

### 1. Header

- Displays the Amazon logo and a **Deliver to India** label.
- Shows **English**, **Account & Lists**, **Returns & Orders**, and **Cart** elements.
- Includes a search-style bar. Its search icon takes users to the collections section; it does **not** perform a product search.

### 2. Navigation Menu

- Contains links to sections such as **Electronics, Fashion, Home & Living, Beauty, Toys,** and **Pet Care**.
- These links help visitors jump to the corresponding categories on the same webpage.

### 3. Hero Section

- Displays a promotional shopping banner with product imagery.
- Includes an introductory heading and a link to explore the collections on smaller screens.

### 4. Highlights Section

- Introduces **curated categories**, **eight featured collections**, and the **mobile-friendly design**.

### 5. Shop Section

Displays eight shopping categories with images and short descriptions:

1. Clothing
2. Health & Personal Care
3. Furniture
4. Mobiles & Gadgets
5. Beauty Picks
6. Pet Care
7. Toys & Games
8. Fashion Trends

Each category includes a **Browse on Amazon.in** link that opens the corresponding search on the official Amazon India website. The website itself does not sell products.

### 6. Promotional Section

- Includes an additional promotional panel titled **Big inspiration. Simple browsing.**
- Provides a link to the official Amazon India website.

### 7. Footer

- Contains links to the website's collections and to selected Amazon India pages.
- Includes a **Back to top** link and the creator credit:

  **Made with HTML & CSS • Made by Drishi Raj**

## Responsive Design

The website uses CSS media queries to adjust its layout for desktop, tablet, and mobile screen sizes.

## How to Run the Project

1. Download or clone the repository.
2. Keep `index.html`, `style.css`, and the `images/` folder in their original structure.
3. Open `index.html` in a web browser, or run it using **Live Server** in VS Code.
